## Podcast

### The MAD Podcast with Matt Turck: Cloudflare CEO: Bot Takeover, Edge AI & The Hard Decision Every CEO Will Face

The Takeaway：Cloudflare CEO Matthew Prince 认为互联网已经跨过一个结构性拐点：bot 和 AI-agent traffic 已经超过 human traffic，这会改变基础设施、安全和 web 的商业模式。

Prince 的视角重要，是因为 Cloudflare 位于相当大一部分互联网流量前面。他说，bot 过去只是相对稳定的少数流量，但 AI-driven scraping、agents 和 automation 增长太快，导致 automated traffic 在 2026 年上半年就超过 human traffic，比 Cloudflare 自己此前的预测更早。

实际影响不只是更多负载。Prince 预计，随着 agents 代表个人和公司浏览、抓取、比较和交易，互联网流量可能扩大几个数量级。这会创造围绕 edge compute、AI gateways、agent authentication、bot management 和 safe delegation 的新基础设施市场。它也会打破广告资助 web 的一个核心假设：bots 不会点击广告。

更难听但更重要的 CEO lesson 是组织问题。Prince 把 AI 描述为迫使公司重新评估工作如何完成，而不是给旧流程加几个 copilots。这期内容把 Cloudflare 自己的 AI infrastructure push 和很多公司将面对的管理难题连在一起：当 agents 可以承担更多 operational work 时，哪些 teams、tools 和 processes 仍然成立？

## Blog

### Claude Blog: Building intelligent apps for Apple platforms with Claude in the Foundation Models framework

Anthropic 正在通过一个 Swift package 为 Apple's Foundation Models framework 增加 Claude support，让 Apple developers 可以在 on-device model tasks 和 Claude 的更强 reasoning、code generation、web search、tool use、data-analysis capabilities 之间做干净的 handoff。关键设计点是 typed Swift values：apps 可以先用 Apple framework 做快速本地 summarization 或 extraction，再把 structured outputs 传给 Claude，而不是直接传 raw user text。

实际模式是 native apps 里的 hybrid intelligence。Journaling app 可以先在本地生成 prompts，再让 Claude 从几个月的 entries 里找长期主题；study app 可以先在本地解释术语，当学生继续追问更深问题时再交给 Claude。这个 package 被描述为会处理 streaming、tool calls，以及回到 SwiftUI views 的 structured responses。

可用性围绕 Apple 下一代平台：iOS 27、iPadOS 27、macOS 27、visionOS 27 和 watchOS 27，developers 通过 Anthropic API key 登录使用。
https://claude.com/blog/claude-for-foundation-models
